# Frozen source-data acquisition and package boundary

This local candidate supports **analysis-ready panel to frozen primary results**. It does not independently reproduce raw sources to the panel. The original source objects are **not bundled**. `project/provenance/source_object_manifest.csv` records original source identity, version, object keys, retrieval evidence and checksums where available; its entries are provenance, not files in this ZIP. Public source availability and byte identity may have changed.

The included `project/src/` is the original historical pipeline code. Some upstream scripts refer to external caches, authority files, credentials or historical paths that are not present. The accepted panel was constructed using the frozen method authorities in `methods/` and the original, now omitted, raw data and intermediate objects. These scripts are retained for provenance, **not** advertised as a turnkey source-to-panel reproduction command.

For the supported reproduction, run `python verify_derivative_candidate.py`, `python reproduce_primary.py --write-report`, the supplied primary inference tests, and the verifier again. The result script reads bundled panel, GEFS aggregate, design and accepted outputs. It does not re-estimate robustness, CR2, Conley, or all manuscript figures/tables, and it is not independent-host validation. See `README.md` and `THIRD_PARTY_NOTICES.md`.
